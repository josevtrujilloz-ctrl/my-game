# Snake game specification

Build a small, offline Snake game in one index.html file using plain HTML, CSS, and JavaScript. No frameworks, installations, or internet dependencies. It must work when opened in the player's own browser.

## Acceptance criteria

1. The snake is light green with a friendly face. It moves continuously using the four arrow keys, with its body following the head's path. Movement should appear smooth. Immediate reversals into the snake's neck are prevented.
2. Eating a pellet adds one body segment and one point. A new pellet appears in an empty space inside the board.
3. The head touching any of the four walls or any part of its own body immediately ends the game. The walls have shading that gives them a 3D appearance.
4. After game over, the screen shows pellets eaten, elapsed playing time, and best score. Best score persists across restarts while the page stays open; retaining it after closing or reloading the page is not required.
5. A Restart button begins a new game with the original snake length, zero points, and a reset timer, while preserving the best score.
## Playtesting
Ask players where they got stuck or bored.
